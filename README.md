# Boss Auto Greet

Chrome/Edge (MV3) 扩展：在 Boss直聘 搜索页按你的条件筛出岗位进入队列，你审批后，
扩展以拟人节奏逐个自动打招呼。全套安全护栏内建。

## 安装
1. 打开 `chrome://extensions`（或 `edge://extensions`）→ 开启「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本文件夹
3. 手动登录 https://www.zhipin.com （扩展复用你的登录会话，不碰验证码）

## 使用
1. 点扩展图标设置：搜索词、标题必须包含、主题词、屏蔽词、城市、公司筛选、每日上限、活动间隔、招呼语
2. 面板上只有一个主键「**开始打招呼**」（运行中变「暂停」）
   - 它比对的是"本页搜的词"和"设置里的搜索词"。改了搜索词后直接点它就会跳到新搜索，不用手动改地址
   - 你在 Boss 自己界面上加的学历/经验等筛选条件不会被冲掉（只比对搜索词和城市）
   - 页面和设置不一致时，面板会用蓝色横条提前告诉你
3. 下面依次是「扫描本页」「清空队列」，再往下是「调试」
4. 队列上方一行有「**全选**」「**全不选**」，也能逐个勾选；只影响待处理的岗位，已招呼过的不动
5. 面板顶部黄色**状态条**实时显示进度：等待 → 选择岗位 → 点击立即沟通 → 已招呼 → 返回列表

## 搜索词 / 标题必须包含 / 主题词（重要）
三个字段职责完全分开，没有隐藏规则：

| 字段 | 作用 | 匹配范围 |
| --- | --- | --- |
| **搜索词**（单个） | 填进 Boss 搜索框，决定「搜什么」 | Boss 服务端**语义**匹配 |
| **标题必须包含**（可多个，可留空） | 对结果卡一道硬门槛 | 只看**岗位标题**，逐字，**命中任一即保留** |
| **主题词**（可多个，可留空） | 对结果再筛一遍方向 | 看**整张卡片**（标题/标签/公司/地点/薪资），逐字，**命中任一即保留** |

- 主题词是「或」的关系，不是「且」。写 `数据, AI, Agent` 表示这三个方向的岗位都要，
  不要求一个岗位同时出现这三个词
- 所以**主题词写得越多，结果越多**。找数据与 AI 方向可以再补 `算法, 机器学习, 大模型, 推荐, NLP`
- 搜索词已经决定了方向，**不要把它重复填进「主题词」**
- Boss 的实习岗卡片上写的是「在校/应届」，**不是「实习」**。把「实习」填进主题词会把结果全部过滤掉
- 一个岗位一个主题词都不命中才会被过滤掉，留空则完全不筛

### 为什么需要「标题必须包含」
Boss 自己的搜索比较松：搜「实习生」返回的结果里夹着一堆根本不是实习的岗位。
「主题词」是拿**整张卡片**的文字去匹配的，而那些非实习岗的卡片上往往也带着
「在校/应届」之类的字样，所以整卡匹配拦不住它们。这一项只看标题，是补的硬门槛。

- 搜「实习生」时这里填 **`实习`**，不要填 `实习生` —— Boss 上有「数据分析实习」「实习-算法」这种标题
- 多个词是「或」的关系，可以写 `实习, 见习, intern`
- 它和「主题词」是叠加的：标题这道门槛过了，还要再过主题词那一关
- 被它拦掉时提示会写 `标题里没有「实习」`

被过滤时，「扫描本页」的提示会直接告诉你主要原因，例如
`不符筛选 15（主要原因：未命中主题词「数据/AI/Agent」×15）`。

## 公司筛选
不想什么公司都投，用这三项，都默认关闭：

| 设置 | 作用 |
| --- | --- |
| **屏蔽公司** | 只比对公司名，逗号分隔。岗位描述里提到这家公司不会被误杀 |
| **屏蔽外包中介** | 一个勾选项，拦掉带 外包/劳务/派遣/人力资源服务/人事代理/人才服务/众包/猎头/驻场 的岗位 |
| **只投有 logo 的公司** | 跳过还在用 Boss 默认头图的公司，通常是没认真做主页的皮包公司 |

- 「屏蔽公司」和「屏蔽关键词」的区别：前者只看公司名，后者看整张卡片
- 「屏蔽外包中介」的词表写在代码里（`AGENCY_WORDS`），比对整张卡片。
  `猎头` 和 `驻场` 有可能误伤非中介公司的相关岗位，觉得漏得多就把这项关掉，改用「屏蔽公司」点名

### 默认 logo 是怎么认出来的
没写死图片地址，而是靠一个事实：**没上传过 logo 的公司拿到的是同一张默认图**。
所以扫描时先把本页所有卡片解析出来，按 logo 地址分组，
一张图被**三家以上不同公司**共用就判定为默认图。

- 数的是**公司数**不是卡片数。一家大公司在本页挂十个岗位，logo 当然重复十次，这不会被误判
- 卡片上**读不到** logo 时（选择器失效、图片还没加载）**一个岗位都不会拦**，
  否则选择器一旦失效就会把整页清空 —— 这是专门写了回归测试钉住的
- 文件名里带 default / nologo / placeholder 这类词的会被直接判定为默认图，
  用于本页卡片太少、凑不出三家公司的情况
- 判定结果可以点面板的「调试」核对，里面有一段「公司 logo 分组」，
  每组都标了 `判定=默认图` 还是 `判定=真 logo`

## 执行流程
```
搜索页 → 选中卡片 → 右侧详情出现「立即沟通」→ 点击 → 跳聊天页
聊天页 → (发自定义招呼语) → 计数+1、标记已招呼 → 跳回搜索页 → 下一个
```
状态存在 storage，每次页面加载自动接续，导航不会打断循环。

搜索结果是**瀑布式加载**的：从聊天页返回时列表会重新加载，只渲染第一批卡片，
队列里排在后面的岗位此时还不在页面上。所以执行器会自己往下滚动把后续批次加载出来，
直到找到目标卡片或滚到底；滚动途中新出现的岗位也会顺带入队。
按「暂停」会在两批之间生效，不用等它滚完。

信息流每次加载出来的岗位不完全一样，所以队列里的岗位有可能在下一次加载时整个消失。
滚到底仍找不到时，扩展不会停在那里，而是：
- 把找不到的岗位标成「**已消失**」（列表里灰显），运行结束而不是暂停
- 把本次扫描的数字摊开告诉你为什么没有可投的（新增 / 已在队列 / 已招呼过 / 不符筛选 + 主要原因）
- 这些岗位以后再被刷出来时会**自动恢复**成待处理，不需要手动清队列
**不跳独立 `job_detail.html`**——Boss 会把深链重定向弹回列表。

## 护栏
- 活动间隔只有一个数字（默认 20 秒），实际等待在设定值上下浮动 30%，节奏不会变成固定周期
- 每日上限（跨日自动重置）
- 检测到验证码立即暂停并通知
- 模拟真实鼠标事件点击，不直接调接口
- 「继续沟通」= 已联系过的岗位自动跳过，不重复骚扰
- 已打过招呼的 jobId **永久记录且无法重置**，清空队列后也绝不会重复打

## 使用要点
- 面板可以**拖动**：按住深色标题栏拖到任意位置，位置会记住，页面跳转后还在原处
- 点标题栏右侧的 `—` 收起，只留标题栏；`+` 展开。收起状态同样会记住

## 测试
```
node tests/run.js                       # 逻辑层，204 项断言
open tests/dom.html                     # 面板 DOM 层，58 项断言（浏览器里看左下角输出）
```
`run.js` 覆盖筛选规则与原因文案、标题硬门槛（含「卡片正文提到也救不回坏标题」的回归）、默认 logo 判定（含「一家公司多个岗位」和
「选择器失效不清空整页」两个回归）、间隔抖动范围、搜索 URL 构造、页面类型判定、
旧配置迁移（含旧的间隔区间折成单值）、已招呼去重、扫描原因统计，
并钉住已删除的设置不再回来。
`dom.html` 加载真实内容脚本，用合成鼠标事件验证按钮层级、拖动、边界钳制、
收起时内联样式不再漏出、点收起按钮不会误触发拖动、搜索词不一致提示、全选与全不选、
公司 logo 的读取（src / data-src / srcset / 无图，以及不把 HR 头像当成公司 logo），
以及瀑布流下滚加载（含「岗位排在后面几批」的回归用例和暂停中断）。

## 风险提醒
自动化仍违反平台用户协议，封号风险降低但非归零。建议低配额、非主力账号先跑，
观察无限流再逐步放开。
