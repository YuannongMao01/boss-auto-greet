# Boss Auto Greet

Chrome/Edge (MV3) 扩展：在 Boss直聘 搜索页按你的条件筛出岗位进入队列，你审批后，
扩展以拟人节奏逐个自动打招呼。全套安全护栏内建。

## 安装
1. 打开 `chrome://extensions`（或 `edge://extensions`）→ 开启「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本文件夹
3. 手动登录 https://www.zhipin.com （扩展复用你的登录会话，不碰验证码）

## 使用
1. 点扩展图标设置：搜索词、必须包含、屏蔽词、城市、薪资下限、每日上限、间隔、招呼语
2. 面板上只有一个主键「**开始打招呼**」（运行中变「暂停」）
   - 它比对的是"本页搜的词"和"设置里的搜索词"。改了搜索词后直接点它就会跳到新搜索，不用手动改地址
   - 你在 Boss 自己界面上加的学历/经验等筛选条件不会被冲掉（只比对搜索词和城市）
   - 页面和设置不一致时，面板会用蓝色横条提前告诉你
3. 下面依次是「扫描本页」「清空队列」，再往下是「调试」
4. 队列上方一行有「**全选**」「**全不选**」，也能逐个勾选；只影响待处理的岗位，已招呼过的不动
5. 面板顶部黄色**状态条**实时显示进度：等待 → 选择岗位 → 点击立即沟通 → 已招呼 → 返回列表

## 搜索词 vs 必须包含（重要）
两个字段职责完全分开，没有隐藏规则：

| 字段 | 作用 | 匹配方式 |
| --- | --- | --- |
| **搜索词**（单个） | 填进 Boss 搜索框，决定「搜什么」 | Boss 服务端**语义**匹配 |
| **必须包含**（可多个，可留空） | 对搜到的结果再筛一遍 | 本地**逐字**匹配卡片文本 |

- 搜索词已经决定了方向，**不要把它重复填进「必须包含」**
- Boss 的实习岗卡片上写的是「在校/应届」，**不是「实习」**。把「实习」填进"必须包含"会把结果全部过滤掉
- 找算法实习：搜索词 = `算法实习`，必须包含**留空**
- 「必须包含」适合的是搜索词覆盖不到的硬条件，例如搜索词 `算法` + 必须包含 `Python`

被过滤时，「扫描本页」的提示会直接告诉你主要原因，例如
`不符筛选 15（主要原因：缺少必含词「实习」×15）`。

## 执行流程
```
搜索页 → 选中卡片 → 右侧详情出现「立即沟通」→ 点击 → 跳聊天页
聊天页 → (发自定义招呼语) → 计数+1、标记已招呼 → 跳回搜索页 → 下一个
```
状态存在 storage，每次页面加载自动接续，导航不会打断循环。
**不跳独立 `job_detail.html`**——Boss 会把深链重定向弹回列表。

## 护栏
- 随机间隔（默认 8~30 秒，不固定）
- 每日上限（跨日自动重置）
- 检测到验证码立即暂停并通知
- 模拟真实鼠标事件点击，不直接调接口
- 「继续沟通」= 已联系过的岗位自动跳过，不重复骚扰
- 已打过招呼的 jobId **永久记录且无法重置**，清空队列后也绝不会重复打

## 使用要点
- 面板可以**拖动**：按住深色标题栏拖到任意位置，位置会记住，页面跳转后还在原处
- 点标题栏右侧的 `—` 收起，只留标题栏；`+` 展开。收起状态同样会记住

## 测试
```
node tests/run.js                       # 逻辑层，50 项断言
open tests/dom.html                     # 面板 DOM 层，25 项断言（浏览器里看左下角输出）
```
`run.js` 覆盖薪资解析、筛选规则与原因文案、搜索 URL 构造、页面类型判定、旧配置迁移、
已招呼去重、扫描原因统计。
`dom.html` 加载真实内容脚本，用合成鼠标事件验证按钮层级、拖动、边界钳制、
收起时内联样式不再漏出、点收起按钮不会误触发拖动、搜索词不一致提示、全选与全不选。

## 风险提醒
自动化仍违反平台用户协议，封号风险降低但非归零。建议低配额、非主力账号先跑，
观察无限流再逐步放开。
